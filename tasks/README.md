# Engineering work orders

Use one Markdown file per order. Cite the task ID in pull requests and Dropbox handoffs. Update status and record decisions here so GitHub preserves the history.

Each order includes an owner or worker, status, objective, scope, deliverables, acceptance criteria, and review decision. Project owners approve the transition from Draft to Ready. Assign approved work manually.
